# ТЗ: офлайн-конвертер файлов с «колесом» для Windows

Рабочее название: **DropWheel**. Личный проект, без коммерции.

## 1. Идея

Пользователь тащит файл мышкой (из проводника, с рабочего стола, из браузера), нажимает горячую клавишу — под курсором появляется круговое меню («колесо») с вариантами конвертации. Бросает файл на нужный сектор — рядом с исходником появляется сконвертированный файл. Всё локально, без интернета.

Дублирующий вход: пункт «Конвертировать…» в контекстном меню проводника.

## 2. Платформа и стек

- Windows 10/11 x64.
- C# + WPF, .NET 8. Одно приложение, живёт в трее.
- Движки — внешние консольные утилиты, лежат в папке `tools/` рядом с exe:
  - **ffmpeg** (LGPL-сборка) — видео, аудио, GIF;
  - **ImageMagick** portable (или libvips) — изображения, включая HEIC/AVIF.
- Настройки — `%AppData%\DropWheel\settings.json`.
- Логи — `%AppData%\DropWheel\logs\`.

## 3. Горячая клавиша

- Клавиша **настраивается**. По умолчанию — **Пробел** (не конфликтует с проводником: Shift/Ctrl/Alt во время перетаскивания там уже означают «переместить / копировать / ярлык»).
- Альтернативы в настройках: `` ` ``, CapsLock, F-клавиши, Shift/Ctrl/Alt.
- Клавиша перехватывается (не доходит до других программ) **только** во время перетаскивания. В остальное время ведёт себя как обычно.
- Повторное нажатие той же клавиши, пока колесо открыто, переключает режим: **Конвертация ↔ Инструменты**.
- Esc — закрыть колесо.

## 4. Как ловим перетаскивание

1. Глобальный low-level хук мыши (`WH_MOUSE_LL`): левая кнопка зажата и курсор сдвинулся больше чем на ~10 px → состояние «возможно, идёт перетаскивание».
2. Глобальный low-level хук клавиатуры (`WH_KEYBOARD_LL`): если в этом состоянии нажата горячая клавиша → показываем колесо под курсором.
3. Колесо — прозрачное окно поверх всех (`Topmost`, без рамки, `AllowDrop = true`).
4. Если файл реально тащат — окно получает `DragEnter`, по типу файла строим сектора.
5. Если `DragEnter` не пришёл, а кнопку мыши отпустили — тихо прячем колесо (значит, тащили не файл, а окно или текст).
6. Учесть несколько мониторов и масштаб экрана (DPI-aware, Per-Monitor V2).

## 5. Колесо

- Круг ~260 px, до 8 секторов, в центре — «Отмена».
- Наведение на сектор подсвечивает его, подпись формата крупно.
- Набор секторов зависит от типа файла (по расширению). Если файлов несколько разного типа — показываем только общие варианты.
- Неподдерживаемый файл — колесо с одной надписью «Нечего предложить», drop = отмена.

## 6. MVP: что умеет

### Изображения (JPG, PNG, WebP, HEIC, AVIF, BMP, TIFF, GIF-статичный)
- Конвертация: → JPG, PNG, WebP, AVIF, PDF.
- Инструменты: сжать (JPG/WebP качество 80), уменьшить в 2 раза, уменьшить до 1920 по длинной стороне, убрать метаданные.

### Видео (MP4, MOV, MKV, WebM, AVI)
- Конвертация: → MP4 (H.264), WebM, GIF (до 15 fps, ширина ≤ 640), MP3 (извлечь звук).
- Инструменты: сжать (CRF 28), уменьшить до 720p, убрать звук.

### Аудио (MP3, M4A, WAV, FLAC, OGG, Opus)
- Конвертация: → MP3 (192k), M4A, WAV, FLAC, OGG.
- Инструменты: нормализовать громкость.

## 7. Результат

- Файл кладётся **рядом с исходником**: `photo.heic` → `photo.jpg`.
- Если имя занято — `photo (1).jpg`, `photo (2).jpg`. **Исходник никогда не перезаписывается и не удаляется.**
- Опция в настройках: класть всё в одну папку (например, `Загрузки\DropWheel`).

## 8. Очередь и обратная связь

- Конвертации идут в фоне, не больше 2 одновременно.
- Иконка в трее показывает, что идёт работа; по клику — мини-окно со списком задач и прогрессом (для ffmpeg — по `-progress`).
- По завершении — системное уведомление Windows «Готово: photo.jpg» с кнопкой «Показать в папке».
- Ошибка — уведомление с короткой причиной, подробности в лог.

## 9. Контекстное меню проводника

- Пункт «Конвертировать…» для поддерживаемых расширений, регистрация через реестр в `HKCU` (без прав администратора, без shell-расширения).
- Клик открывает то же колесо (или компактное списочное меню) у курсора; выбор = запуск конвертации.
- Работает с несколькими выделенными файлами (второй экземпляр приложения передаёт пути первому через named pipe).
- На Windows 11 пункт окажется в «Показать дополнительные параметры» — для MVP это нормально.

## 10. Настройки (простое окно)

- Горячая клавиша.
- Куда класть результат: рядом / в общую папку.
- Качество по умолчанию: JPG/WebP, CRF видео, битрейт MP3.
- Автозапуск с Windows.
- Вкл/выкл пункт в контекстном меню.
- Пути к ffmpeg / magick (по умолчанию — `tools/`).

## 11. Архитектура

```
DropWheel/
  App/            трей, точка входа, single-instance, named pipe
  Input/          глобальные хуки мыши и клавиатуры, детектор перетаскивания
  Wheel/          окно колеса, отрисовка секторов, drop
  Conversions/    каталог операций: тип файла → список операций
  Engines/        обёртки над ffmpeg и ImageMagick (запуск процесса, прогресс, ошибки)
  Jobs/           очередь задач, именование выходных файлов
  Shell/          регистрация контекстного меню, уведомления
  Settings/       модель настроек, окно настроек
DropWheel.Cli/    консольная утилита: dropwheel convert <файл> <операция> — для тестов без UI
DropWheel.Tests/  тесты на каталог операций, именование файлов, сборку аргументов ffmpeg/magick
```

Каталог операций — декларативный (одна запись = id, подпись, входные расширения, движок, шаблон аргументов, выходное расширение), чтобы новые форматы добавлялись одной строкой.

## 12. Этапы

1. **Ядро без UI.** `Engines` + `Conversions` + `Jobs` + CLI. Готово, когда `dropwheel convert photo.heic to-jpg` создаёт `photo.jpg` и тесты зелёные.
2. **Трей + контекстное меню.** Готово, когда правый клик по видео → «Конвертировать…» → MP4 работает, приходит уведомление.
3. **Колесо по горячей клавише при перетаскивании.** Готово, когда сценарий из раздела 1 работает из проводника и с рабочего стола, на двух мониторах, при масштабе 100% и 150%, и колесо не появляется при перетаскивании окон или текста.
4. **Настройки и полировка.** Окно настроек, автозапуск, смена клавиши.

## 13. На потом (не в MVP)

- PDF: склеить, разбить, сжать, в картинки (qpdf).
- Документы: DOCX/ODT/PPTX/XLSX → PDF через LibreOffice headless (если установлен).
- Markdown/DOCX/EPUB/HTML через pandoc.
- Видео: обрезка по времени, кадрирование.
- Архивы: упаковать в ZIP / распаковать (7-Zip).
- Пакетная обработка папки целиком.
- Встроенные редакторы (по референсу Tangerine): обрезка картинки с пропорциями (Free, 1:1, 16:9, 9:16, 4:3, 3:4), «добавить фон» (палитра, отступы, скругление, тень), аннотации.

## 14. Указания для Claude Code

- Начинать с этапа 1, UI не трогать, пока CLI и тесты не работают.
- Не изобретать конвертацию — только вызывать ffmpeg/magick с проверенными аргументами.
- Хуки держать в отдельном классе с аккуратным снятием при выходе; обработчик хука должен быть быстрым (тяжёлое — в другой поток).
- Все пути к файлам — с кавычками и поддержкой кириллицы и пробелов; проверить на файле `Мои фото\тест 1.heic`.
- Перед каждым этапом коротко описать план, после — что проверено вручную.
