# Ручная проверка на Windows

## Быстрая проверка — 15 минут (начните с неё)

**Установка.** https://github.com/Luchano55/dropwheel/releases/tag/dev-build → скачать `DropWheel-win-x64.zip` → распаковать в обычную папку (например, `C:\DropWheel`, не в Program Files) → запустить `DropWheel.exe`. SmartScreen: «Подробнее» → «Выполнить в любом случае». У часов — подсказка «DropWheel работает».

Подготовьте папку `Мои фото` с фото (HEIC или JPG), коротким видео, PDF, документом Word и Excel.

1. [ ] **Колесо.** Зажмите фото, потащите, нажмите **Пробел** → под курсором колесо. Наведите на «PNG» → лепесток подсвечен, в центре «PNG». Бросьте → рядом `фото.png`, уведомление «Готово» с превью.
2. [ ] **Режимы.** С колесом на экране ещё раз Пробел → «Инструменты» (Сжать, Уменьшить…). Esc → колесо закрылось, ничего не произошло.
3. [ ] **Меню проводника.** Правый клик по видео → (Windows 11: «Показать дополнительные параметры») → «Конвертировать…» → то же колесо у курсора, кликом «MP4».
4. [ ] **Окно задач.** Клик по значку в трее → панель с задачами, прогресс, «Открыть», «Показать в папке».
5. [ ] **PDF.** Колесо на PDF → «PNG страницы» → папка со страницами. Два PDF вместе → «Склеить».
6. [ ] **Word/Excel.** Колесо на DOCX → «PDF» (первый раз 3–5 с, потом ~1 с, окно Word **не должно** появиться). Excel → «CSV» открывается двойным кликом правильно.
7. [ ] **Архивы.** Несколько файлов → «В ZIP». Колесо на ZIP/7Z → «Распаковать».
8. [ ] **Обычная жизнь.** Пробел в тексте и в видеоплеере работает как обычно, когда вы ничего не тащите.
9. [ ] **Вид.** Колесо круглое, **без квадрата** вокруг; в тёмной теме Windows — тёмное. Анимация открытия плавная.
10. [ ] **Обновление.** Трей → «Проверить обновления» → «Обновлений нет» (или предложит обновиться).

Если что-то не так: правый клик по значку DropWheel в трее → «Открыть журнал» → пришлите последний `.log` и номер пункта. Подробные проверки по темам — ниже.

## Этап 2 — трей и «Конвертировать…» в проводнике

Подготовка: положите в папку `C:\Тест\Мои фото` пару файлов — фото с телефона (HEIC или JPG), короткое видео (MP4/MOV), песню (MP3).

1. **Запуск.** Двойной клик по `DropWheel.exe`. Окна нет — в трее (у часов, может быть под стрелкой «^») появился значок-кольцо из синих плиток с оранжевой.
   - [ ] значок появился
2. **Пункт меню.** Правый клик по видео → на Windows 11 «Показать дополнительные параметры» → «Конвертировать…».
   - [ ] пункт есть у фото, видео и музыки
   - [ ] у документа (DOCX, ZIP) пункта нет
3. **Видео → MP4** (главная проверка этапа). «Конвертировать…» → у курсора колесо → лепесток «MP4».
   - [ ] на значке в трее появился оранжевый кружок с цифрой 1
   - [ ] пришло уведомление «Готово: … .mp4», кнопка «Показать в папке» открывает папку с выделенным файлом
   - [ ] файл играет, исходник на месте
4. **Список задач.** Левый клик по значку в трее → окно со списком: миниатюра, имя, полоска прогресса, «Готово».
   - [ ] прогресс видео движется (возьмите видео подлиннее)
   - [ ] кнопка «Отмена» останавливает задачу, недоделанного файла не остаётся
5. **Несколько файлов.** Выделите 3 фото → «Конвертировать…».
   - [ ] колесо появилось один раз, в центре — общий размер трёх файлов
   - [ ] после выбора «JPG» появились 3 файла
   - [ ] выделите 20 файлов — пункт меню всё ещё есть (проверяем, снят ли предел в 15 файлов)
6. **Разные типы.** Выделите фото и видео вместе → «Конвертировать…» → «Нечего предложить».
   - [ ] так и есть
7. **Ошибка.** Переименуйте любой текстовый файл в `сломанный.jpg` → «Конвертировать…» → «PNG».
   - [ ] уведомление с короткой причиной, кнопка «Подробнее» открывает журнал с подробностями
8. **Программа не запущена.** Трей → «Выход». Затем «Конвертировать…» на фото.
   - [ ] DropWheel сам запустился, показал меню, сконвертировал
9. **Выключить пункт меню.** Трей → снять галочку «Пункт „Конвертировать…“ в проводнике».
   - [ ] пункт исчез из меню проводника; галочка обратно — вернулся
10. **Кириллица и пробелы.** Всё выше — в папке `Мои фото`, файл `тест 1.heic`.
    - [ ] работает

## Этап 3 — колесо по горячей клавише при перетаскивании

Горячая клавиша — **Пробел**. DropWheel должен быть запущен (значок в трее).

1. **Главный сценарий.** Зажмите левой кнопкой фото в проводнике, потащите (не отпуская) → нажмите Пробел.
   - [ ] под курсором появилось колесо с форматами (JPG, PNG, WebP…)
   - [ ] при наведении лепесток заливается цветом акцента, его название — в «пилюле» в центре
   - [ ] бросили на «PNG» → рядом с исходником появился PNG, пришло уведомление
   - [ ] пробел при этом не «напечатался» никуда
2. **Режимы.** Колесо открыто → ещё раз Пробел.
   - [ ] сектора сменились на «Инструменты» (Сжать, Уменьшить…), ещё раз — обратно
3. **Отмена.**
   - [ ] Esc закрывает колесо (файл остаётся там, где был)
   - [ ] бросить в центр («Отмена») — ничего не происходит
   - [ ] отпустить кнопку мимо колеса — колесо исчезает
4. **С рабочего стола.** То же с файлом на рабочем столе.
   - [ ] работает
5. **Не файл.** Перетащите окно за заголовок и нажмите Пробел; выделите текст в браузере, потащите, нажмите Пробел.
   - [ ] колесо либо не появляется, либо исчезает при отпускании кнопки; ничего не ломается
6. **Пробел в обычной жизни.** Печатайте текст, смотрите видео (пробел = пауза).
   - [ ] пробел работает как обычно
7. **Задержка секторов (D10).** Сразу после Пробела сектора видны, или появляются только после движения мыши?
   - [ ] отметьте, что видите
8. **Мониторы и масштаб.** Если есть второй монитор: повторите п. 1 на каждом. Затем «Параметры → Дисплей → Масштаб» 150% и снова.
   - [ ] колесо под курсором, одного размера, не обрезано краем экрана/панелью задач
9. **Выход.** Трей → «Выход».
   - [ ] мышь и клавиатура работают без задержек

## Этап 4 — настройки

Откройте настройки: двойной клик по значку в трее (или правый клик → «Настройки…»).

1. **Окно.**
   - [ ] открывается одно окно «Настройки DropWheel»; повторный двойной клик — то же окно выходит вперёд, второе не появляется
   - [ ] на Windows 11 — полупрозрачный фон Mica, скруглённые углы; на Windows 10 — аккуратный сплошной фон
   - [ ] смените тему Windows (светлая ↔ тёмная) — окно перекрашивается сразу, заголовок тоже
   - [ ] внизу слева — номер сборки; «Проверить обновления» и «Открыть папку журналов» работают
2. **Горячая клавиша — без перезапуска.** «Основное» → выберите **F8**.
   - [ ] тащите фото + F8 — колесо появилось; тащите + Пробел — колеса нет, Пробел ведёт себя как обычно
   - [ ] F8 ещё раз при открытом колесе — режим «Инструменты»
   - [ ] верните Пробел — работает сразу
2а. **Своя клавиша.** «Основное» → «Горячая клавиша» → **Своя…**.
   - [ ] на пилюле — «Нажмите клавишу… (Esc — отмена)»; нажмите **Ctrl** — под пилюлями объяснение, что Ctrl/Shift/Alt/Win нельзя, окно всё ещё ждёт
   - [ ] нажмите **Enter** или **Print Screen** — «не подходит», ждёт дальше; **Esc** — отмена, выбрана прежняя клавиша
   - [ ] снова «Своя…» → нажмите **5 на цифровом блоке** (Num Lock включён) — на пилюле «Num 5»
   - [ ] тащите фото + Num 5 — колесо появилось; Num 5 ещё раз — «Инструменты»; в Блокноте Num 5 печатает «5» как обычно
   - [ ] «Своя…» → буква **Q** — под пилюлями предупреждение, что во время перетаскивания Q не печатается; в Блокноте Q печатается
   - [ ] перезапустите DropWheel — Num 5/Q на месте; в окне задач и подсказке при запуске написана эта клавиша
   - [ ] верните Пробел
3. **Куда класть результат.** «В одну папку» → «Выбрать папку…» → любая папка, например `Мои фото\Результаты`.
   - [ ] конвертируйте фото с рабочего стола — результат появился в выбранной папке, а не рядом
   - [ ] «Рядом с исходником» — следующий результат снова рядом
4. **Качество влияет на размер.** «Качество» → JPG = 50, конвертируйте большое фото в JPG; затем JPG = 100 и ещё раз.
   - [ ] второй файл (`… (1).jpg`) заметно больше первого
   - [ ] видео CRF 30 против 18 — файл меньше; MP3 128 против 320 — файл меньше
5. **Автозапуск.** «Запускать вместе с Windows» — вкл.
   - [ ] в «Диспетчер задач → Автозагрузка» есть DropWheel
   - [ ] перезагрузите компьютер: значок в трее появился сам, **без** всплывающей подсказки «DropWheel работает»
   - [ ] выключите переключатель — запись в «Автозагрузке» пропала; откройте настройки снова — переключатель выключен
6. **Пункт в проводнике.** Выключите «Пункт „Конвертировать…“ в проводнике».
   - [ ] в меню файла пункта нет; в меню значка в трее галочка тоже снята; включите — пункт вернулся
7. **Своё колесо.** «Колесо» → «Фото» → «Конвертация».
   - [ ] перетащите PNG наверх списка (или кнопкой ↑) — мини-колесо справа сразу показывает PNG наверху
   - [ ] снимите галочку у AVIF — его нет ни на мини-колесе, ни на настоящем колесе при перетаскивании фото
   - [ ] то же видно в «Конвертировать…» из проводника
   - [ ] «Сбросить» — порядок и галочки как были
   - [ ] снимите все галочки и в «Конвертации», и в «Инструментах» — колесо для фото всё равно не пустое (обычный порядок)
8. **Последний выбор — первым.** Включите переключатель.
   - [ ] конвертируйте фото в WebP; при следующем перетаскивании фото WebP — на верхнем лепестке
   - [ ] для видео это не действует (у каждого типа — своё), пока не выберете что-то для видео
   - [ ] выключите — порядок снова как в списке
9. **Сохраняется.** Закройте DropWheel (трей → «Выход»), запустите снова.
   - [ ] все настройки на месте (клавиша, папка, качество, порядок колеса)
10. **Английский интерфейс.** «Основное» → «Язык интерфейса» → **English**.
   - [ ] окно настроек сразу по-английски («DropWheel Settings», «General», «Language»…)
   - [ ] правый клик по значку в трее — пункты по-английски: Jobs, Settings…, Open log, Check for updates, Exit
   - [ ] тащите фото + Пробел — в центре колеса «Convert», в инструментах «Compress», «Half size», «No metadata»
   - [ ] «Сжать» → «Compress»: результат называется `… (compressed).jpg`, уведомление «Done: …» с кнопками Open / Show in folder
   - [ ] правый клик по файлу в проводнике — пункт **Convert…** (если не сменился сразу — закройте и откройте окно проводника)
   - [ ] окно задач у трея — «Done», «Clear»; ошибка (например, переименуйте `.txt` в `.jpg` и конвертируйте) — по-английски
   - [ ] верните **Как в Windows**: на русской Windows всё снова по-русски; на английской Windows — остаётся английский
11. **Прозрачность колеса.** «Основное» → «Прозрачность колеса» → ползунок до конца вправо («прозрачнее»).
   - [ ] мини-колесо рядом сразу просвечивает (видны полосы под ним)
   - [ ] тащите фото + Пробел — колесо тоже прозрачнее, подписи и выбранный лепесток (в цвете акцента) читаются как раньше
   - [ ] правый клик по файлу → «Конвертировать…» — то же; вкладка «Колесо» — мини-колесо такое же
   - [ ] ползунок до конца влево («плотнее») — диск непрозрачный; после перезапуска значение сохранилось

## Буфер обмена и видео: повернуть, кадры, обложка

1. **Снимок экрана → колесо.** Нажмите <kbd>Win</kbd>+<kbd>Shift</kbd>+<kbd>S</kbd>, выделите кусок экрана, затем <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>V</kbd>.
   - [ ] у курсора открылось колесо для фото (JPG, WebP, PDF, ICO, «Текст (OCR)»…)
   - [ ] щёлкните JPG — в папке «Изображения\DropWheel» появились `Буфер <дата время>.png` и `Буфер <дата время>.jpg`
   - [ ] если в настройках выбрано «В одну папку» — оба файла там
2. **Три файла из проводника.** Выделите 3 фото, <kbd>Ctrl</kbd>+<kbd>C</kbd>, потом <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>V</kbd>.
   - [ ] колесо — как у «Конвертировать…» для трёх файлов (есть «Один PDF»); выбор → три результата рядом с исходниками
3. **Только текст.** Скопируйте слово из Блокнота, <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>V</kbd>.
   - [ ] колеса нет, всплывает подсказка «В буфере нет картинки или файлов»
4. **Пункт трея и выключатель.** Правый клик по значку → «Из буфера обмена…» (справа написано Ctrl+Alt+V) — то же колесо.
   - [ ] «Настройки» → «Основное» → выключите «Ctrl+Alt+V — колесо для буфера обмена»: сочетание больше не работает, пункт трея — работает; включите — снова работает
   - [ ] там же «Картинки из буфера и браузера» → «Своя папка» → «Выбрать папку…» → например, «Рабочий стол»: снимок экрана + <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>V</kbd> → JPG — оба файла на рабочем столе; «По умолчанию» — снова «Изображения\DropWheel»
   - [ ] выключите «Оставлять исходную картинку»: снимок → <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>V</kbd> → JPG — остался только `Буфер <дата время>.jpg`, PNG нет; если закрыть колесо без выбора — PNG остаётся
5. **Видео.** Тащите видео с телефона (вертикальное) + Пробел.
   - [ ] «Инструменты» → «Повернуть ↻»: `… (повёрнуто).mp4` повёрнут на 90° по часовой, звук есть
   - [ ] «Инструменты» → «Кадры»: папка `… (кадры)` с `кадр-001.jpg`, `кадр-002.jpg`… — по кадру на секунду
   - [ ] «Конвертация» → «JPG (кадр)»: `… (кадр).jpg` — кадр с первой секунды

## Картинки из браузера

Нужны Chrome и Edge (Firefox — по желанию). DropWheel запущен, горячая клавиша — Пробел. Окно браузера
не на весь экран: рядом должно быть видно немного рабочего стола или проводника (колесо появится под курсором где угодно,
но так удобнее). Результаты ищите в «Изображения\DropWheel» (Проводник → «Изображения» → «DropWheel»),
если в настройках не выбрана своя папка.

1. **JPG в Chrome.** Откройте в Chrome статью Википедии с фотографией (например, https://ru.wikipedia.org/wiki/Москва).
   Зажмите левой кнопкой фотографию в статье, потащите чуть в сторону (не отпуская) → нажмите Пробел.
   - [ ] под курсором колесо с форматами для фото (PNG, WebP, PDF…), в центре — размер картинки
   - [ ] бросьте на «PNG» → в «Изображения\DropWheel» появились картинка с её именем с сайта и рядом PNG с тем же именем, пришло уведомление
   - [ ] в браузере ничего не открылось и не сломалось
2. **WebP в Chrome.** Откройте https://www.gstatic.com/webp/gallery/1.webp (картинка на всю вкладку). Тащите её + Пробел.
   - [ ] в колесе есть «JPG» и нет «WebP» (картинка уже WebP)
   - [ ] бросьте на «JPG» → в папке `1.webp` и `1.jpg`; `1.jpg` открывается
3. **PNG с прозрачностью в Edge.** Откройте в Edge
   https://upload.wikimedia.org/wikipedia/commons/4/47/PNG_transparency_demonstration_1.png. Тащите картинку + Пробел.
   - [ ] колесо для фото; бросьте на «WebP» → `PNG_transparency_demonstration_1.webp`, в нём кубики на прозрачном фоне (в «Фотографиях» фон шахматкой или однотонный, а не чёрный)
   - [ ] повторите п. 1 и 2 в Edge — так же, как в Chrome
4. **Одинаковое имя.** Повторите п. 2 ещё раз.
   - [ ] появились `1 (1).webp` и `1 (1).jpg`, старые файлы не тронуты
5. **Текст — колеса нет.** Выделите мышью абзац текста на странице, зажмите выделение и потащите, нажмите Пробел.
   - [ ] колесо не появляется (или мелькает и сразу исчезает); текст никуда не вставился; отпустите кнопку — всё как обычно
   - [ ] то же с обычной ссылкой (зажмите ссылку на другую статью, потащите, Пробел) — колеса нет
6. **Только ссылка на картинку.** На странице https://commons.wikimedia.org/wiki/File:PNG_transparency_demonstration_1.png
   зажмите **ссылку** «Original file» / «Исходный файл» (текст ссылки, не картинку), потащите, нажмите Пробел.
   - [ ] колесо «Нечего предложить» с подсказкой «Только ссылка — сохраните картинку и перетащите файл»; отпустили — ничего не произошло
7. **Настройки.** «Настройки» → «Основное»: карточка называется «Картинки из буфера и браузера».
   - [ ] «Своя папка» → «Рабочий стол», повторите п. 2 — оба файла на рабочем столе; верните «По умолчанию»

## Обрезка видео

Понадобится видео на 20–60 секунд — например, снятое телефоном (MP4 или MOV). Для пункта 6 — ещё одно
в формате MKV или WebM (если нет — пропустите). Положите видео в папку `Мои фото` с пробелом в имени,
например `Мои фото\тест 1.mp4`.

1. **Окно открывается.** Тащите видео, нажмите Пробел, ещё раз Пробел (режим «Инструменты»), бросьте на «Обрезать…».
   - [ ] в середине экрана открылось окно «Обрезать видео» с именем файла и длительностью справа
   - [ ] сначала на секунду — «Читаю видео…», потом появился первый кадр, внизу под ним — полоса из 10 маленьких кадров
   - [ ] под полосой: «Начало 00:00.0», «Длина» и «Конец» — длина ролика; кнопка «Обрезать» пока бледная (выбран весь ролик)
2. **Ручки.** Потяните левую синюю ручку вправо, правую — влево.
   - [ ] время «Начало» / «Конец» / «Длина» меняется, пока тянете; затемнённые края — то, что отрежется
   - [ ] через долю секунды после остановки большой кадр показывает то место, где ручка; в углу кадра — его время
   - [ ] ручки не заходят друг за друга; щелчок по полосе — ближайшая ручка прыгает туда
   - [ ] щёлкните по полосе, затем стрелки ← / → на клавиатуре двигают ручку на 0,1 с, с Shift — на 1 с; Tab — другая ручка
3. **Обрезать быстро.** Выберите кусок, например с 0:05 до 0:12, галочку «Точно по кадру» не ставьте, нажмите «Обрезать».
   - [ ] окно закрылось, почти сразу — уведомление «Готово», рядом с видео появился `тест 1 (обрезано).mp4` (у MOV — `.mov`)
   - [ ] новое видео ~7 секунд (может начаться на долю секунды или пару секунд раньше 0:05 — это нормально без галочки), со звуком
   - [ ] исходный `тест 1.mp4` не изменился (та же длина и размер)
4. **Обрезать точно.** Снова «Обрезать…», тот же кусок, поставьте галочку «Точно по кадру (дольше, с пересжатием)» → «Обрезать».
   - [ ] в окне задач видна полоса прогресса; результат `тест 1 (обрезано) (1).mp4` начинается ровно с выбранного кадра, длина — как в окне
5. **Отмена.** Откройте окно ещё раз и нажмите «Отмена» (или Esc, или крестик).
   - [ ] ничего не создалось; в папке `%TEMP%\DropWheel` не осталось папок `trim-…` (вставьте путь в адресную строку проводника)
6. **MKV / WebM.** То же для MKV или WebM.
   - [ ] кадры и миниатюры показываются (их делает ffmpeg, а не проигрыватель Windows), результат — `… (обрезано).mkv` / `.webm`
7. **Другие входы.** Правый клик по видео → «Конвертировать…» → «Инструменты» → «Обрезать…»; и ещё: видео <kbd>Ctrl</kbd>+<kbd>C</kbd> → <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>V</kbd>.
   - [ ] в обоих случаях открывается то же окно обрезки
8. **Несколько видео.** Тащите сразу два видео + Пробел → «Инструменты».
   - [ ] «Обрезать…» на колесе нет (обрезка — по одному ролику)
9. **Тема.** «Параметры Windows» → «Персонализация» → «Цвета» → тёмный режим (с открытым окном обрезки).
   - [ ] окно перекрашивается сразу; в Windows 11 под окном — лёгкое «стекло» (Mica), как у окна настроек
10. **GIF из куска.** Снова «Обрезать…», выберите кусок секунд на 5 (например, с 0:05 до 0:10), под полосой
    в карточке «Результат» нажмите «GIF».
    - [ ] галочка «Точно по кадру» пропала, вместо неё — строка «GIF — 15 кадров в секунду…», кнопка называется «Сделать GIF»
    - [ ] растяните кусок больше чем на 30 секунд — появилась подсказка «Кусок длиннее 30 секунд — GIF выйдет очень большим»;
          сделайте кусок снова коротким — подсказка исчезла (кнопка всё равно работает и с длинным куском)
    - [ ] нажмите «Сделать GIF»: рядом появился `тест 1 (кусок).gif`; откройте его в браузере (перетащите в окно Edge) —
          он двигается по кругу, без звука, длина — как выбирали, ширина не больше 640 точек
    - [ ] нажмите «Видео» — галочка «Точно по кадру» вернулась, кнопка снова «Обрезать»
    - [ ] исходное видео не изменилось

## Обрезка картинки

Понадобятся: фото с телефона, снятое вертикально (JPG или HEIC), и картинка PNG с прозрачным фоном (например, логотип).
Положите их в папку `Мои фото`, например `Мои фото\тест 1.jpg`.

1. **Окно открывается.** Тащите фото, нажмите Пробел, ещё раз Пробел («Инструменты»), бросьте на «Обрезать…».
   - [ ] открылось окно «Обрезать картинку»: имя файла, справа — размер (например, `3024 × 4032`)
   - [ ] вертикальное фото и показано вертикально (как в проводнике), а не на боку
   - [ ] рамка — по краям всей картинки, под картинкой тот же размер; кнопка «Обрезать» пока бледная
2. **Рамка.** Потяните угол, потом середину края, потом саму рамку изнутри.
   - [ ] вне рамки — затемнено, внутри — линии «третей»; курсор меняется над углами, краями и внутри
   - [ ] размер под картинкой (`Ш × В`) меняется, пока тянете; рамка не выходит за картинку
   - [ ] щёлкните по картинке, стрелки на клавиатуре двигают рамку (с Shift — быстрее)
3. **Пропорции.** Нажмите «1:1», затем «3:4» (у вертикального фото так подписано), затем «Как было», «Свободно».
   - [ ] при «1:1» рамка становится квадратом по центру, при перетаскивании угла остаётся квадратом
   - [ ] «Как было» — снова вся картинка; «Свободно» — рамку можно тянуть как угодно
4. **Обрезать.** Выделите кусок и нажмите «Обрезать» (или Enter).
   - [ ] рядом появился `тест 1 (обрезано).jpg` (у HEIC — `.jpg`), его размер — как был под картинкой, и он не на боку
   - [ ] исходный файл не изменился; повторная обрезка даёт `тест 1 (обрезано) (1).jpg`
5. **Прозрачность.** То же для PNG с прозрачным фоном.
   - [ ] результат — `… (обрезано).png`, фон остался прозрачным
6. **Отмена.** Откройте окно и нажмите «Отмена» (или Esc).
   - [ ] ничего не создалось; в `%TEMP%\DropWheel` не осталось папок `crop-…`
7. **Другие входы и несколько файлов.** Правый клик по фото → «Конвертировать…» → «Инструменты» → «Обрезать…» — то же окно.
   Тащите сразу две картинки → «Инструменты».
   - [ ] при двух картинках «Обрезать…» на колесе нет
8. **Тема.** Переключите тёмный режим Windows при открытом окне.
   - [ ] окно перекрашивается сразу

## Оформить картинку

Понадобятся: снимок экрана (PNG, например `Win`+`Shift`+`S` → сохранить) и фото с телефона, снятое вертикально (JPG).
Положите их в папку `Мои фото`, например `Мои фото\тест 1.png`.

1. **Окно открывается.** Тащите снимок, нажмите Пробел, ещё раз Пробел («Инструменты»), бросьте на «Оформить…».
   - [ ] на колесе «Инструменты» у одной картинки 8 лепестков, «Оформить…» — сразу после «Обрезать…», «В 7Z» на месте
   - [ ] открылось окно «Оформить картинку»: имя файла, справа — размер «было → станет» (например, `1920 × 1080 → 2092 × 1252`)
   - [ ] через секунду в окне — снимок со скруглёнными углами и тенью на розово-сиреневом фоне
2. **Фон.** Нажимайте по очереди «Небо», «Мята», «Белый», «Серый», «Тёмный», «Прозрачный».
   - [ ] картинка в окне меняется почти сразу; у «Прозрачного» вокруг видна шахматка
3. **Ползунки и тень.** Потаскайте «Отступ» и «Скругление», выключите и включите «Тень».
   - [ ] пока тянете, картинка обновляется (с небольшой задержкой), окно не подвисает
   - [ ] «Отступ» 0 — фона почти не видно; «Скругление» 0 — углы прямые (картинка не пропадает!)
   - [ ] размер «станет» в заголовке меняется вместе с отступом
4. **Сохранить.** Нажмите «Сохранить» (или Enter).
   - [ ] рядом появился `тест 1 (оформлено).png`; откройте его — выглядит как в окне
   - [ ] исходный файл не изменился; повтор даёт `тест 1 (оформлено) (1).png`
   - [ ] с «Прозрачным» фоном: вставьте результат в Word или откройте в Paint 3D — углы и поля прозрачные
5. **Копировать.** Откройте окно снова, нажмите «Копировать», затем вставьте (Ctrl+V) в Telegram, Word или Paint.
   - [ ] внизу окна — «Скопировано в буфер обмена»; вставилась оформленная картинка
   - [ ] рядом с исходником ничего нового не появилось
6. **Фото с телефона.** То же для вертикального JPG.
   - [ ] в окне и в результате фото стоит, а не лежит на боку
7. **Отмена и несколько файлов.** Нажмите «Отмена» (или Esc). Потом тащите сразу две картинки → «Инструменты».
   - [ ] ничего не создалось; в `%TEMP%\DropWheel` не осталось папок `beautify-…`
   - [ ] при двух картинках «Оформить…» на колесе нет
8. **Тема и язык.** Переключите тёмный режим Windows при открытом окне; в настройках выберите English и откройте окно снова.
   - [ ] окно перекрашивается сразу; по-английски — «Beautify picture», результат — `тест 1 (styled).png`

## Пароль на PDF

Понадобится любой PDF (например, скачанная выписка или скан). Положите его в папку `Мои фото` с пробелом в имени,
например `Мои фото\тест 1.pdf`. Пароль для проверки придумайте с русскими буквами и пробелом, например `мой пароль 1`.

1. **Колесо.** Тащите PDF, нажмите Пробел, ещё раз Пробел («Инструменты»).
   - [ ] на колесе есть «Защитить…» и «Снять пароль…» (вместе с «Разбить», «Оптимизировать», «Повернуть ↻» и др.)
   - [ ] тащите сразу два PDF → «Инструменты»: этих двух пунктов нет (пароль — по одному файлу)
2. **Защитить.** Бросьте PDF на «Защитить…».
   - [ ] в середине экрана — окно «Защитить PDF паролем» с именем файла, курсор уже стоит в поле «Пароль»
   - [ ] кнопка «Защитить» бледная, пока поля пустые; введите пароль в первое поле, а во второе — другой:
          появилось красное «Пароли не совпадают», кнопка по-прежнему бледная
   - [ ] поставьте галочку «Показать пароль» — вместо точек видны буквы, введённое не пропало; уберите галочку
   - [ ] введите одинаковый пароль в оба поля и нажмите «Защитить» (или Enter)
   - [ ] окно закрылось, пришло уведомление «Готово», рядом появился `тест 1 (защищён).pdf`
3. **Пароль работает.** Откройте `тест 1 (защищён).pdf` двойным щелчком (откроется Edge или ваша программа для PDF).
   - [ ] спрашивает пароль; неверный — не открывает, верный (с русскими буквами и пробелом) — открывает, страницы те же
   - [ ] исходный `тест 1.pdf` открывается без пароля, как раньше
4. **Снять пароль — неверный.** Тащите `тест 1 (защищён).pdf` → «Инструменты» → «Снять пароль…».
   - [ ] окно «Снять пароль с PDF» с одним полем; введите неправильный пароль → «Снять пароль»
   - [ ] пришло уведомление об ошибке «Неверный пароль»; нового файла не появилось
5. **Снять пароль — верный.** То же с правильным паролем.
   - [ ] появился `тест 1 (защищён) (без пароля).pdf`, он открывается без пароля
6. **Уже с паролем.** Тащите `тест 1 (защищён).pdf` → «Защитить…», введите любой пароль.
   - [ ] ошибка «PDF уже защищён паролем — сначала снимите пароль»
7. **Пароль нигде не записан.** Трей → «Открыть журнал» (или папка `%AppData%\DropWheel\logs`), откройте последний файл
   и найдите (Ctrl+F) ваш пароль.

   - [ ] `%AppData%\DropWheel` (настройки и журналы) **остался** — так задумано
6. **winget** (когда пакет примут): `winget install Luchano55.DropWheel` — ставится без вопросов;

1. **После обновления.** Трей → «Обновить до сборки N».
   - [ ] программа перезапустилась; через 2–3 секунды по центру экрана — окно «Что нового в DropWheel X.Y.Z» со списком изменений

   - [ ] то же окно открывается сразу и получает фокус; повторный щелчок по пункту не открывает второе окно

## Документы Microsoft Office

Нужен установленный Microsoft Office (Word, Excel, PowerPoint — что есть). Подготовка: в папке `C:\Тест\Мои документы` — документ Word (`отчёт 1.docx`), таблица Excel (`таблица 1.xlsx`, лучше с двумя листами), презентация (`доклад 1.pptx`), любой PDF.

   - [ ] первый раз — несколько секунд, рядом появился `отчёт 1.pdf`, открывается
   - [ ] сразу ещё раз «DOC», затем «TXT» — заметно быстрее (Word уже запущен); TXT открывается в Блокноте с русскими буквами

2. **Ваш Word не трогаем.** Откройте любой документ в Word, напечатайте пару слов, не сохраняйте. Сконвертируйте `отчёт 1.docx` в PDF.
   - [ ] ваш документ на месте, текст не пропал, Word не закрылся
3. **Excel.** `таблица 1.xlsx` → «PDF» (все листы), «CSV» (только первый лист), «ODS».
   - [ ] файлы появились; CSV открывается в Excel по столбцам, кириллица на месте
4. **PowerPoint.** `доклад 1.pptx` → «PDF», «Слайды PNG».
   - [ ] появились `доклад 1.pdf` и папка `доклад 1 (слайды)` с `слайд-1.png`… — картинки чёткие

5. **PDF → Word.** Любой PDF → «DOCX».
   - [ ] появился DOCX с текстом; никаких окон с вопросами
   - [ ] тот же PDF → «Markdown»: появился `.md` (открыть Блокнотом) — заголовки начинаются с `#`, списки с `-`, таблицы из `|`; рядом не осталось временного DOCX и скрытой папки `.dropwheel-tmp`
   - [ ] тот же PDF → «MD (быстро)»: `.md` появляется почти сразу — в нём текст PDF абзацами (без `#` и таблиц); на ПК без Word есть только этот лепесток

7. **Простой и выход.** Диспетчер задач → «Подробности»: после конвертаций там есть `WINWORD.EXE` / `EXCEL.EXE` (наш скрытый).
   - [ ] через 5–6 минут без конвертаций он исчез сам
   - [ ] сконвертируйте снова, затем трей → «Выход» — исчез сразу
8. **Word закрыли.** После конвертации завершите `WINWORD.EXE` в диспетчере задач, сконвертируйте ещё раз.
   - [ ] работает (Word запустился заново)
9. **Автотесты Office** (если есть желание): `dotnet test tests/DropWheel.Windows.Tests` в папке исходников — тесты Office на ПК с Office не пропускаются, в выводе видно время каждой конвертации.

## UX — как всё должно выглядеть и ощущаться

Смотрите глазами, ставьте галочку, если «да». Если что-то выглядит странно — пришлите скриншот (Win+Shift+S).

1. **Колесо — стекло.** Потащите фото, нажмите Пробел.
   - [ ] колесо «вырастает» из точки под курсором, с лёгким пружинящим эффектом, примерно за четверть секунды
   - [ ] колесо круглое; сквозь него размыто видно обои/окна (матовое стекло), вокруг — мягкая тень
   - [ ] вокруг колеса **нет** размытого квадрата или тёмных углов (если есть — скриншот обязательно)
   - [ ] лепестки — отдельные скруглённые плашки с ровными зазорами; форматы — крупно, прописными (JPG, PNG…), без значков
   - [ ] в центре в «пилюле» — размер файла («2,4 МБ»); наводите на лепесток — он плавно заливается цветом акцента Windows, подпись белая, в пилюле — название формата
   - [ ] курсор в центр — в пилюле «Отмена»
2. **Инструменты.** Ещё раз Пробел.
   - [ ] лепестки быстро сменяются с лёгким поворотом; у каждого инструмента — значок над подписью («Сжать», «Без метаданных»)
   - [ ] две точки под пилюлей показывают, какой режим открыт
3. **Бросок.** Бросьте файл на лепесток.
   - [ ] лепесток коротко «вспыхивает», колесо быстро исчезает
4. **Тема.** «Параметры → Персонализация → Цвета»: переключите светлый/тёмный режим и цвет акцента, снова откройте колесо.
   - [ ] колесо и окно задач в новой теме, подсветка — новым цветом акцента
   - [ ] выключите «Эффекты прозрачности» — колесо становится плотным (без размытия), но с тенью и аккуратным
5. **Без анимаций.** «Параметры → Специальные возможности → Визуальные эффекты → Эффекты анимации» — выкл.
   - [ ] колесо и окна появляются сразу, без движения
6. **«Конвертировать…» в проводнике.**
   - [ ] у курсора появляется то же колесо; клик по лепестку — запуск
   - [ ] Tab или правая кнопка мыши — смена «Конвертация ↔ Инструменты»; стрелки и колёсико мыши — выбор лепестка, Enter — запуск
   - [ ] Esc или клик мимо колеса — колесо закрывается
7. **Окно задач.** Запустите пару конвертаций, щёлкните значок в трее.
   - [ ] окно появляется над значками у часов (если панель задач сверху/сбоку — у неё), плавно «выезжает»
   - [ ] на Windows 11 — скруглённые углы и полупрозрачный фон; на Windows 10 — аккуратное прямоугольное окно
   - [ ] у каждой задачи — миниатюра файла, полоска прогресса движется плавно; у готовых — зелёная галочка и кнопки «Открыть» и «Показать в папке»; у ошибки — причина и «Подробнее» (открывает журнал)
   - [ ] «Очистить» убирает завершённые; щелчок мимо окна или ещё раз по значку — окно прячется
   - [ ] пустое окно — значок и подсказка, как начать
8. **Уведомления.**
   - [ ] после конвертации фото в уведомлении видна картинка-превью, есть кнопки «Открыть» и «Показать в папке»
   - [ ] выделите 5 фото → «Конвертировать…» → JPG: приходит **одно** уведомление «Готово: 5 файлов», кнопка открывает папку с выделенными файлами
9. **Значок.** 
   - [ ] в трее — новый значок (кольцо из синих плиток с оранжевой); пока идёт работа — оранжевый кружок с числом задач
   - [ ] у `DropWheel.exe` в проводнике тот же значок
   - [ ] меню значка (правая кнопка) — в цвет темы панели задач (тёмное при тёмной теме)
