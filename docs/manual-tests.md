# Ручная проверка на Windows

Как получить сборку: https://github.com/Luchano55/dropwheel/releases/tag/dev-build → `DropWheel-win-x64.zip` → распаковать, например, в `C:\DropWheel`.
Если что-то пошло не так — в трее правый клик по значку DropWheel → «Открыть журнал», пришлите последний файл `.log`.

## Этап 2 — трей и «Конвертировать…» в проводнике

Подготовка: положите в папку `C:\Тест\Мои фото` пару файлов — фото с телефона (HEIC или JPG), короткое видео (MP4/MOV), песню (MP3).

1. **Запуск.** Двойной клик по `DropWheel.exe`. Окна нет — в трее (у часов, может быть под стрелкой «^») появился значок-кольцо из синих плиток с оранжевой.
   - [ ] значок появился
2. **Пункт меню.** Правый клик по видео → на Windows 11 «Показать дополнительные параметры» → «Конвертировать…».
   - [ ] пункт есть у фото, видео и музыки
   - [ ] у документа (DOCX, ZIP) пункта нет
3. **Видео → MP4** (главная проверка этапа). «Конвертировать…» → у курсора колесо → лепесток «MP4».
   - [ ] на значке в трее появился оранжевый кружок с цифрой 1
   - [ ] пришло уведомление «Готово: … .mp4», кнопка «Показать в папке» открывает папку с выделенным файлом
   - [ ] файл играет, исходник на месте
4. **Список задач.** Левый клик по значку в трее → окно со списком: миниатюра, имя, полоска прогресса, «Готово».
   - [ ] прогресс видео движется (возьмите видео подлиннее)
   - [ ] кнопка «Отмена» останавливает задачу, недоделанного файла не остаётся
5. **Несколько файлов.** Выделите 3 фото → «Конвертировать…».
   - [ ] колесо появилось один раз, в центре — общий размер трёх файлов
   - [ ] после выбора «JPG» появились 3 файла
   - [ ] выделите 20 файлов — пункт меню всё ещё есть (проверяем, снят ли предел в 15 файлов)
6. **Разные типы.** Выделите фото и видео вместе → «Конвертировать…» → «Нечего предложить».
   - [ ] так и есть
7. **Ошибка.** Переименуйте любой текстовый файл в `сломанный.jpg` → «Конвертировать…» → «PNG».
   - [ ] уведомление с короткой причиной, кнопка «Подробнее» открывает журнал с подробностями
8. **Программа не запущена.** Трей → «Выход». Затем «Конвертировать…» на фото.
   - [ ] DropWheel сам запустился, показал меню, сконвертировал
9. **Выключить пункт меню.** Трей → снять галочку «Пункт „Конвертировать…“ в проводнике».
   - [ ] пункт исчез из меню проводника; галочка обратно — вернулся
10. **Кириллица и пробелы.** Всё выше — в папке `Мои фото`, файл `тест 1.heic`.
    - [ ] работает

## Этап 3 — колесо по горячей клавише при перетаскивании

Горячая клавиша — **Пробел**. DropWheel должен быть запущен (значок в трее).

1. **Главный сценарий.** Зажмите левой кнопкой фото в проводнике, потащите (не отпуская) → нажмите Пробел.
   - [ ] под курсором появилось колесо с форматами (JPG, PNG, WebP…)
   - [ ] при наведении лепесток заливается цветом акцента, его название — в «пилюле» в центре
   - [ ] бросили на «PNG» → рядом с исходником появился PNG, пришло уведомление
   - [ ] пробел при этом не «напечатался» никуда
2. **Режимы.** Колесо открыто → ещё раз Пробел.
   - [ ] сектора сменились на «Инструменты» (Сжать, Уменьшить…), ещё раз — обратно
3. **Отмена.**
   - [ ] Esc закрывает колесо (файл остаётся там, где был)
   - [ ] бросить в центр («Отмена») — ничего не происходит
   - [ ] отпустить кнопку мимо колеса — колесо исчезает
4. **С рабочего стола.** То же с файлом на рабочем столе.
   - [ ] работает
5. **Не файл.** Перетащите окно за заголовок и нажмите Пробел; выделите текст в браузере, потащите, нажмите Пробел.
   - [ ] колесо либо не появляется, либо исчезает при отпускании кнопки; ничего не ломается
6. **Пробел в обычной жизни.** Печатайте текст, смотрите видео (пробел = пауза).
   - [ ] пробел работает как обычно
7. **Задержка секторов (D10).** Сразу после Пробела сектора видны, или появляются только после движения мыши?
   - [ ] отметьте, что видите
8. **Мониторы и масштаб.** Если есть второй монитор: повторите п. 1 на каждом. Затем «Параметры → Дисплей → Масштаб» 150% и снова.
   - [ ] колесо под курсором, одного размера, не обрезано краем экрана/панелью задач
9. **Выход.** Трей → «Выход».
   - [ ] мышь и клавиатура работают без задержек

## UX — как всё должно выглядеть и ощущаться

Смотрите глазами, ставьте галочку, если «да». Если что-то выглядит странно — пришлите скриншот (Win+Shift+S).

1. **Колесо — стекло.** Потащите фото, нажмите Пробел.
   - [ ] колесо «вырастает» из точки под курсором, с лёгким пружинящим эффектом, примерно за четверть секунды
   - [ ] колесо круглое; сквозь него размыто видно обои/окна (матовое стекло), вокруг — мягкая тень
   - [ ] вокруг колеса **нет** размытого квадрата или тёмных углов (если есть — скриншот обязательно)
   - [ ] лепестки — отдельные скруглённые плашки с ровными зазорами; форматы — крупно, прописными (JPG, PNG…), без значков
   - [ ] в центре в «пилюле» — размер файла («2,4 МБ»); наводите на лепесток — он плавно заливается цветом акцента Windows, подпись белая, в пилюле — название формата
   - [ ] курсор в центр — в пилюле «Отмена»
2. **Инструменты.** Ещё раз Пробел.
   - [ ] лепестки быстро сменяются с лёгким поворотом; у каждого инструмента — значок над подписью («Сжать», «Без метаданных»)
   - [ ] две точки под пилюлей показывают, какой режим открыт
3. **Бросок.** Бросьте файл на лепесток.
   - [ ] лепесток коротко «вспыхивает», колесо быстро исчезает
4. **Тема.** «Параметры → Персонализация → Цвета»: переключите светлый/тёмный режим и цвет акцента, снова откройте колесо.
   - [ ] колесо и окно задач в новой теме, подсветка — новым цветом акцента
   - [ ] выключите «Эффекты прозрачности» — колесо становится плотным (без размытия), но с тенью и аккуратным
5. **Без анимаций.** «Параметры → Специальные возможности → Визуальные эффекты → Эффекты анимации» — выкл.
   - [ ] колесо и окна появляются сразу, без движения
6. **«Конвертировать…» в проводнике.**
   - [ ] у курсора появляется то же колесо; клик по лепестку — запуск
   - [ ] Tab или правая кнопка мыши — смена «Конвертация ↔ Инструменты»; стрелки и колёсико мыши — выбор лепестка, Enter — запуск
   - [ ] Esc или клик мимо колеса — колесо закрывается
7. **Окно задач.** Запустите пару конвертаций, щёлкните значок в трее.
   - [ ] окно появляется над значками у часов (если панель задач сверху/сбоку — у неё), плавно «выезжает»
   - [ ] на Windows 11 — скруглённые углы и полупрозрачный фон; на Windows 10 — аккуратное прямоугольное окно
   - [ ] у каждой задачи — миниатюра файла, полоска прогресса движется плавно; у готовых — зелёная галочка и кнопки «Открыть» и «Показать в папке»; у ошибки — причина и «Подробнее» (открывает журнал)
   - [ ] «Очистить» убирает завершённые; щелчок мимо окна или ещё раз по значку — окно прячется
   - [ ] пустое окно — значок и подсказка, как начать
8. **Уведомления.**
   - [ ] после конвертации фото в уведомлении видна картинка-превью, есть кнопки «Открыть» и «Показать в папке»
   - [ ] выделите 5 фото → «Конвертировать…» → JPG: приходит **одно** уведомление «Готово: 5 файлов», кнопка открывает папку с выделенными файлами
9. **Значок.** 
   - [ ] в трее — новый значок (кольцо из синих плиток с оранжевой); пока идёт работа — оранжевый кружок с числом задач
   - [ ] у `DropWheel.exe` в проводнике тот же значок
   - [ ] меню значка (правая кнопка) — в цвет темы панели задач (тёмное при тёмной теме)
