# Ручная проверка на Windows

Как получить сборку: https://github.com/Luchano55/dropwheel/releases/tag/dev-build → `DropWheel-win-x64.zip` → распаковать, например, в `C:\DropWheel`.
Если что-то пошло не так — в трее правый клик по значку DropWheel → «Открыть журнал», пришлите последний файл `.log`.

## Этап 2 — трей и «Конвертировать…» в проводнике

Подготовка: положите в папку `C:\Тест\Мои фото` пару файлов — фото с телефона (HEIC или JPG), короткое видео (MP4/MOV), песню (MP3).

1. **Запуск.** Двойной клик по `DropWheel.exe`. Окна нет — в трее (у часов, может быть под стрелкой «^») появился серый значок-кольцо.
   - [ ] значок появился
2. **Пункт меню.** Правый клик по видео → на Windows 11 «Показать дополнительные параметры» → «Конвертировать…».
   - [ ] пункт есть у фото, видео и музыки
   - [ ] у документа (DOCX, ZIP) пункта нет
3. **Видео → MP4** (главная проверка этапа). «Конвертировать…» → у курсора меню → «→ MP4».
   - [ ] значок в трее стал синим с цифрой 1
   - [ ] пришло уведомление «Готово: … .mp4», кнопка «Показать в папке» открывает папку с выделенным файлом
   - [ ] файл играет, исходник на месте
4. **Список задач.** Левый клик по значку в трее → окно со списком: имя, полоска прогресса, «Готово».
   - [ ] прогресс видео движется (возьмите видео подлиннее)
   - [ ] кнопка «Отмена» останавливает задачу, недоделанного файла не остаётся
5. **Несколько файлов.** Выделите 3 фото → «Конвертировать…».
   - [ ] меню появилось один раз, вверху «Файлов: 3»
   - [ ] после выбора «→ JPG» появились 3 файла
   - [ ] выделите 20 файлов — пункт меню всё ещё есть (проверяем, снят ли предел в 15 файлов)
6. **Разные типы.** Выделите фото и видео вместе → «Конвертировать…» → «Нечего предложить».
   - [ ] так и есть
7. **Ошибка.** Переименуйте любой текстовый файл в `сломанный.jpg` → «Конвертировать…» → «→ PNG».
   - [ ] уведомление с короткой причиной, в журнале подробности
8. **Программа не запущена.** Трей → «Выход». Затем «Конвертировать…» на фото.
   - [ ] DropWheel сам запустился, показал меню, сконвертировал
9. **Выключить пункт меню.** Трей → снять галочку «Пункт „Конвертировать…“ в проводнике».
   - [ ] пункт исчез из меню проводника; галочка обратно — вернулся
10. **Кириллица и пробелы.** Всё выше — в папке `Мои фото`, файл `тест 1.heic`.
    - [ ] работает

## Этап 3 — колесо по горячей клавише при перетаскивании

Горячая клавиша — **Пробел**. DropWheel должен быть запущен (значок в трее).

1. **Главный сценарий.** Зажмите левой кнопкой фото в проводнике, потащите (не отпуская) → нажмите Пробел.
   - [ ] под курсором появилось колесо с форматами (JPG, PNG, WebP…)
   - [ ] при наведении сектор подсвечивается, крупная подпись в центре
   - [ ] бросили на «PNG» → рядом с исходником появился PNG, пришло уведомление
   - [ ] пробел при этом не «напечатался» никуда
2. **Режимы.** Колесо открыто → ещё раз Пробел.
   - [ ] сектора сменились на «Инструменты» (Сжать, Уменьшить…), ещё раз — обратно
3. **Отмена.**
   - [ ] Esc закрывает колесо (файл остаётся там, где был)
   - [ ] бросить в центр («Отмена») — ничего не происходит
   - [ ] отпустить кнопку мимо колеса — колесо исчезает
4. **С рабочего стола.** То же с файлом на рабочем столе.
   - [ ] работает
5. **Не файл.** Перетащите окно за заголовок и нажмите Пробел; выделите текст в браузере, потащите, нажмите Пробел.
   - [ ] колесо либо не появляется, либо исчезает при отпускании кнопки; ничего не ломается
6. **Пробел в обычной жизни.** Печатайте текст, смотрите видео (пробел = пауза).
   - [ ] пробел работает как обычно
7. **Задержка секторов (D10).** Сразу после Пробела сектора видны, или появляются только после движения мыши?
   - [ ] отметьте, что видите
8. **Мониторы и масштаб.** Если есть второй монитор: повторите п. 1 на каждом. Затем «Параметры → Дисплей → Масштаб» 150% и снова.
   - [ ] колесо под курсором, одного размера, не обрезано краем экрана/панелью задач
9. **Выход.** Трей → «Выход».
   - [ ] мышь и клавиатура работают без задержек

## Документы Microsoft Office

Нужен установленный Microsoft Office (Word, Excel, PowerPoint — что есть). Подготовка: в папке `C:\Тест\Мои документы` — документ Word (`отчёт 1.docx`), таблица Excel (`таблица 1.xlsx`, лучше с двумя листами), презентация (`доклад 1.pptx`), любой PDF.

1. **Word → PDF.** Перетащите `отчёт 1.docx`, Пробел → колесо: PDF, DOC, ODT, RTF, TXT, HTML, Markdown (DOCX нет — он уже DOCX). Бросьте на «PDF».
   - [ ] первый раз — несколько секунд, рядом появился `отчёт 1.pdf`, открывается
   - [ ] сразу ещё раз «DOC», затем «TXT» — заметно быстрее (Word уже запущен); TXT открывается в Блокноте с русскими буквами
   - [ ] на экране за всё время не мелькнуло ни одного окна Word
2. **Ваш Word не трогаем.** Откройте любой документ в Word, напечатайте пару слов, не сохраняйте. Сконвертируйте `отчёт 1.docx` в PDF.
   - [ ] ваш документ на месте, текст не пропал, Word не закрылся
3. **Excel.** `таблица 1.xlsx` → «PDF» (все листы), «CSV» (только первый лист), «ODS».
   - [ ] файлы появились; CSV открывается в Excel по столбцам, кириллица на месте
4. **PowerPoint.** `доклад 1.pptx` → «PDF», «Слайды PNG».
   - [ ] появились `доклад 1.pdf` и папка `доклад 1 (слайды)` с `слайд-1.png`… — картинки чёткие
   - [ ] то же при открытом у вас PowerPoint (с другой презентацией) — ваша презентация не закрылась
5. **PDF → Word.** Любой PDF → «DOCX».
   - [ ] появился DOCX с текстом; никаких окон с вопросами
6. **Пароль.** Сохраните документ Word с паролем (Файл → Сведения → Защита документа → Зашифровать с паролем) → «PDF».
   - [ ] быстро пришло уведомление «Документ защищён паролем»
7. **Простой и выход.** Диспетчер задач → «Подробности»: после конвертаций там есть `WINWORD.EXE` / `EXCEL.EXE` (наш скрытый).
   - [ ] через 5–6 минут без конвертаций он исчез сам
   - [ ] сконвертируйте снова, затем трей → «Выход» — исчез сразу
8. **Word закрыли.** После конвертации завершите `WINWORD.EXE` в диспетчере задач, сконвертируйте ещё раз.
   - [ ] работает (Word запустился заново)
9. **Автотесты Office** (если есть желание): `dotnet test tests/DropWheel.Windows.Tests` в папке исходников — тесты Office на ПК с Office не пропускаются, в выводе видно время каждой конвертации.

## Документы без Office и печать в PDF через Edge

Удобнее на ПК **без** Office (или проверьте только пункты 3–5). Подготовка: в `C:\Тест\Мои документы` — `отчёт 1.docx` с заголовками, списком, таблицей и картинкой, `таблица 1.xlsx`, `заметки.md`, любой `.txt` и `.csv` (например, выгрузка из банка).

1. **Word → PDF без Office.** `отчёт 1.docx` → «PDF».
   - [ ] первый раз — пара секунд, рядом `отчёт 1.pdf`; ни одного окна не мелькнуло
   - [ ] в PDF — те же шрифты, списки, таблица и картинка, поля как в Word («почти как в Word»: страницы могут разбиться иначе, колонтитулов нет)
   - [ ] у `старый.doc` / `.rtf` сектора «PDF» нет (без Office их не открыть)
2. **Word → TXT, Excel → CSV без Office.** `отчёт 1.docx` → «TXT», `таблица 1.xlsx` → «CSV».
   - [ ] TXT открывается в Блокноте с русскими буквами
   - [ ] двойной щелчок по CSV открывает его в Excel сразу по столбцам, кириллица и числа на месте
3. **Word → HTML / Markdown.** `отчёт 1.docx` → «HTML» и «Markdown».
   - [ ] HTML открывается в браузере и похож на документ (с картинкой); Markdown — в Блокноте, читается
4. **CSV → XLSX.** Любой `.csv` → «XLSX».
   - [ ] Excel открывает файл, столбцы разделены, числа — числами (выравнены вправо), коды вроде `007` не потеряли нули
5. **Текст → PDF.** `заметки.md` → «HTML» и «PDF»; любой `.txt` и `.html` → «PDF».
   - [ ] PDF аккуратные (A4), таблицы и код в Markdown не вылезают за край, картинки из Markdown на месте
6. **Простой.** Диспетчер задач → «Подробности»: после печати в PDF есть процессы `msedgewebview2.exe`.
   - [ ] через 2–3 минуты без печати они исчезли; трей → «Выход» — исчезли сразу
