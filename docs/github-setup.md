# Оформление страницы на GitHub — что сделать руками

Всё ниже делается в браузере на github.com, войдя в аккаунт **Luchano55**. Займёт минут 20–30 (плюс запись демо-GIF).

Готовые картинки лежат в `docs/assets/`: логотип `logo.svg`, шапка `banner.svg`, картинка для соцсетей `social-preview.png` (её исходник — `social-preview.svg`), схема «как это работает» `how-it-works.svg` и временная анимация `demo.gif`.

## 1. Чтобы новое описание было видно на странице проекта

GitHub показывает README из **основной ветки**. Сейчас основная ветка — `main`, а в ней только самый первый файл. Пока работа не попала в `main`, посетители видят пустую страницу.

1. Попросите Claude: «Слей рабочую ветку в main» — или сделайте сами: вкладка **Pull requests** → **New pull request** → слева `base: main`, справа рабочая ветка (например `claude/stage3-wheel`) → **Create pull request** → **Merge pull request**.
2. Проверьте: на главной странице репозитория https://github.com/Luchano55/dropwheel видна шапка с колесом и значки.
3. Сейчас тестовую сборку `dev-build` выкладывает только ветка `claude/dropwheel-stage1` (см. `.github/workflows/build.yml`). Когда основной станет `main`, попросите Claude переключить выпуск сборок на `main`.

## 3. Картинка для соцсетей (social preview)

Эта картинка показывается, когда ссылку на репозиторий отправляют в Telegram, VK, X, Slack и т. д.

1. Скачайте её: откройте в репозитории `docs/assets/social-preview.png` → кнопка **Download raw file** (стрелка вниз справа над картинкой).
2. Вкладка **Settings** репозитория → раздел **General** → прокрутите до **Social preview** → **Edit** → **Upload an image…** → выберите скачанный `social-preview.png`.
3. Картинка 1280×640, меньше 1 МБ — подходит под требования GitHub.

## 4. Закрепить проект в профиле

1. Откройте свой профиль: https://github.com/Luchano55
2. Блок **Popular repositories** / **Pinned** → **Customize your pins**.
3. Отметьте `dropwheel` → **Save pins**.

## 5. Включить Discussions (обсуждения)

Там люди задают вопросы и делятся идеями, не засоряя список ошибок. На них уже ссылается форма «New issue».

1. **Settings** → **General** → раздел **Features** → поставьте галочку **Discussions**.
2. Появится вкладка **Discussions** → **Set up discussions** → GitHub предложит первое сообщение. Можно написать коротко, например:
   > Welcome! Ask questions, share ideas and show how you use DropWheel. Пишите по-английски или по-русски.
3. Там же, в **Features**, можно снять **Wiki** и **Projects** — они не используются.

## 6. Скриншоты колеса

Картинки колеса рисуются автоматически при каждой сборке (тест `WheelScreenshots`). README ждёт их в папке `docs/assets/screenshots/` с именами:

- `wheel-photo-convert.png`
- `wheel-photo-tools.png`
- `wheel-video-convert.png`
- `wheel-pdf-convert.png`

Пока файлов нет, на их месте в README будут пустые рамки. Проще всего попросить Claude: «Скопируй свежие скриншоты колеса в docs/assets/screenshots». Вручную:

1. Вкладка **Actions** → последний зелёный запуск **build** → внизу **Artifacts** → **screenshots** — скачается zip. (Свежие картинки также лежат в ветке `screenshots`, в папке с именем ветки.)
2. Распакуйте его.
3. В репозитории откройте папку `docs/assets/screenshots` → **Add file** → **Upload files** → перетащите четыре PNG с именами из списка выше → **Commit changes**.

## 7. Демо-GIF

Самое важное для «звёзд»: живая анимация вверху README. Сейчас там нарисованная заглушка с подписью «Illustration» — её нужно заменить настоящей записью экрана.

### Подготовка

1. Установите **ScreenToGif** (бесплатная, с открытым кодом): https://www.screentogif.com → **Download**. Или в терминале: `winget install NickeManarin.ScreenToGif`.
2. Масштаб экрана — 100% (**Параметры → Система → Дисплей → Масштаб**), чтобы всё было чётким.
3. Уберите лишнее: закройте другие окна, спокойные обои, на рабочем столе — ничего личного.
4. Откройте небольшое окно проводника с папкой, где лежит фото, например `photo.heic` (крупные значки: **Вид → Крупные значки**). DropWheel запущен.

### Запись

1. Запустите ScreenToGif → **Recorder** (Запись).
2. Внизу рамки впишите размер **800 × 450** и частоту **15** fps. Перетащите рамку так, чтобы в неё попали окно проводника и место, где появится колесо.
3. Нажмите **Record** (F7), подождите секунду и спокойно, без резких движений:
   - зажмите фото и потащите в сторону;
   - нажмите **Пробел** — появится колесо;
   - наведите на «JPG», задержитесь на полсекунды, отпустите;
   - подождите, пока рядом появится `photo.jpg`.
4. Нажмите **Stop** (F8). Всё вместе — 5–8 секунд. Если не понравилось — запишите ещё раз, это нормально.

### Обработка и сохранение

1. Откроется **Editor**. Удалите лишние кадры в начале и в конце: выделите их внизу (Shift+клик) → **Delete**.
2. Если ширина больше 800: вкладка **Image** → **Resize** → ширина **800**, пропорции сохранить.
3. **File → Save as**: тип **GIF**, кодировщик — **ScreenToGif** (или **FFmpeg**, если предложит). Имя файла — **`demo.gif`**.
4. Проверьте размер файла: нужно **меньше 5 МБ**. Если больше — вкладка **Edit** → **Remove duplicates** (удалить одинаковые кадры), потом снова сохраните; можно ещё укоротить запись.
5. Замените файл в репозитории: откройте папку `docs/assets` → **Add file** → **Upload files** → перетащите свой `demo.gif` → **Commit changes**. Имя должно остаться `demo.gif` — README подхватит его сам.

Совет: вторым коротким роликом можно показать переключение режимов (ещё раз **Пробел** → «Инструменты») или меню «Конвертировать…» в проводнике — пришлите его Claude, он добавит в README.
