## Как это работает

1. **Потащите** любой файл — из проводника, с рабочего стола, из окна папки. Кнопку мыши не отпускайте.
2. **Нажмите <kbd>Пробел</kbd>.** Под курсором появится колесо форматов. Ещё раз <kbd>Пробел</kbd> — переключение **Конвертация ↔ Инструменты**; <kbd>Esc</kbd> — закрыть.
3. **Бросьте** файл на сектор. Всё: `photo.heic` превращается в `photo.jpg` в той же папке, а уведомление сообщит, что готово.

Без перетаскивания: правый клик по файлу → **«Конвертировать…»**.

## Возможности

- 🎯 **Прямо под курсором** — не нужно открывать программу и искать «Сохранить как».
- ✈️ **100% офлайн** — ffmpeg, ImageMagick, qpdf и poppler лежат в архиве, файлы никуда не отправляются.
- 🛡️ **Исходник не трогается** — никогда не перезаписывается и не удаляется.
- 📚 **Много файлов сразу** — сконвертировать пачку, склеить PDF, собрать фото в один PDF, упаковать в один ZIP.
- ⚡ **Очередь в фоне** — до двух задач одновременно, прогресс в трее, уведомление с кнопкой «Показать в папке».
- 🖱️ **Меню проводника** — «Конвертировать…» для одного файла или выделения, без прав администратора.
- 📦 **Без установки** — распаковал и запустил, .NET ставить не нужно.
- 🔤 **Любые имена** — кириллица, пробелы, длинные пути: `Мои фото\тест 1.heic` работает.
- 💸 **Бесплатно и с открытым кодом** — лицензия MIT, без рекламы и ограничений.

## Что умеет

| Тип | Конвертация | Инструменты |
|---|---|---|
| Фото (JPG, PNG, WebP, HEIC, AVIF, BMP, TIFF, GIF; на вход также SVG, PSD и RAW фотокамер — CR2, CR3, NEF, ARW, DNG, RAF, ORF, RW2) | `to-jpg` `to-png` `to-webp` `to-avif` `to-pdf` · `img-ico` значок ICO (256…16 px, прозрачный фон) · `img-ocr` текст с картинки в .txt (распознавание Windows, только в приложении; JPG, PNG, BMP, TIFF) · для GIF: `gif-to-mp4` `gif-to-webm` анимация → видео | `img-compress` сжать · `img-half` уменьшить ×2 · `img-1920` до 1920 px · `img-strip` убрать метаданные · `images-to-pdf` несколько фото в один PDF |
| Видео (MP4, MOV, MKV, WebM, AVI) | `to-mp4` `to-webm` `to-gif` `video-to-mp3` | `video-compress` сжать · `video-720p` · `video-mute` убрать звук · `video-subs` субтитры в `фильм.srt` |
| Звук (MP3, M4A, WAV, FLAC, OGG, Opus) | `to-mp3` `to-m4a` `to-wav` `to-flac` `to-ogg` | `audio-normalize` выровнять громкость |
| PDF | `pdf-to-png` `pdf-to-jpg` — каждая страница картинкой, в папку `документ (страницы)` | `pdf-merge` склеить несколько PDF · `pdf-split` разбить по страницам · `pdf-optimize` оптимизировать без потери качества |
| Текст (TXT, CSV, SRT, MD, INI, LOG, XML, JSON) | — | `text-to-utf8` перекодировать в UTF-8 (из Windows-1251, DOS-866, UTF-16): `заметки (UTF-8).txt` |
| Любые файлы, ZIP | — | `zip-pack` упаковать в ZIP (несколько файлов — в один архив) · `zip-extract` распаковать ZIP в папку |

Исходный файл никогда не меняется и не удаляется. Если имя занято — `photo (1).jpg`. Инструменты добавляют пометку: `photo (сжато).jpg`.

Колесо предлагает только то, что подходит к файлу: для `.jpg` не будет «→ JPG», для видео — «→ PDF». Если файлов несколько и они разных типов — только общие варианты.

<details>
<summary><b>🚧 В работе</b> — документы Office, OCR, 7-Zip, значки, RAW</summary>

<br>

- **Документы Office → PDF** — DOC/DOCX/RTF/ODT, XLS/XLSX/ODS/CSV, PPT/PPTX/ODP: через установленный Microsoft Office (заранее «прогретый», чтобы было быстро) или встроенными библиотеками и печатью через Edge, если Office нет.
- **Текст и веб-страницы → PDF** — TXT, Markdown, HTML.
- **OCR** — распознать текст на сканах и фото.
- **Архивы 7-Zip** — 7z, RAR и другие.
- **Значки** — `.ico` из картинки.
- **RAW-фото** — прямо с фотоаппарата в JPG.

</details>

## Установка

1. Откройте страницу **Releases** репозитория → релиз **«Тестовая сборка»** (`dev-build`) → скачайте `DropWheel-win-x64.zip`. Прямая ссылка: [последняя сборка](https://github.com/Luchano55/dropwheel/releases/tag/dev-build).
2. Распакуйте архив куда угодно, например в `C:\DropWheel`. Внутри: `DropWheel.exe` (программа), `dropwheel-cli.exe`, папка `tools` (ffmpeg, ImageMagick, qpdf, poppler) и `try-dropwheel.cmd`. Папка `tools` должна лежать рядом с `DropWheel.exe`.
3. Запустите **`DropWheel.exe`**. Окна нет — в трее (у часов, может быть под стрелкой «^») появится значок-кольцо. Теперь можно тащить файл и жать <kbd>Пробел</kbd>.
4. Если Windows покажет «Windows защитила ваш компьютер» — нажмите «Подробнее» → «Выполнить в любом случае» (программа не подписана, это нормально для личного проекта). Каждую сборку делает [GitHub Actions](https://github.com/Luchano55/dropwheel/actions/workflows/build.yml) прямо из кода этого репозитория.

Дальше программа обновляется сама: когда выходит новая сборка, в меню значка появляется пункт **«Обновить до сборки N»** — один клик, и DropWheel скачает её, проверит и перезапустится.

**Требования:** Windows 10 (1809 и новее) или Windows 11, 64-бит. Больше ничего ставить не нужно.

**Удаление:** правый клик по значку → снять галочку «Пункт „Конвертировать…“ в проводнике» (пункт меню исчезнет) → «Выход». Потом удалите папку программы и, если хотите, `%AppData%\DropWheel` (настройки и журналы).

## Как пользоваться

### 🎡 Колесо: перетаскивание + <kbd>Пробел</kbd>

| Что делаете | Что происходит |
|---|---|
| Тащите файл и жмёте <kbd>Пробел</kbd> | под курсором появляется колесо |
| Ещё раз <kbd>Пробел</kbd> | режим **Конвертация** ↔ **Инструменты** |
| Наводите на сектор | он подсвечивается, в центре — крупная подпись |
| Бросаете на сектор | конвертация; готовый файл появится рядом с исходным |
| Бросаете в центр («Отмена»), жмёте <kbd>Esc</kbd> или отпускаете мимо | ничего не происходит |

<kbd>Пробел</kbd> перехватывается только во время перетаскивания — в остальное время он, как обычно, печатает пробелы и ставит видео на паузу.

### 🖱️ Меню проводника

Правый клик по одному или нескольким файлам → **«Конвертировать…»** → выберите операцию в меню у курсора. На Windows 11 пункт — в «Показать дополнительные параметры» (или <kbd>Shift</kbd>+<kbd>F10</kbd>). Если DropWheel не запущен, он запустится сам.

### 🔔 Значок в трее

- **Левый клик** — окно задач: прогресс и кнопка «Отмена».
- **Правый клик** — «Задачи», включение/выключение пункта в проводнике, «Открыть журнал», «Проверить обновления», «Выход».
- Пока идёт работа, значок синий с цифрой.

### ⌨️ Консольный режим

**Самый простой способ:** перетащите любой файл (фото, видео, музыку) мышкой на `try-dropwheel.cmd`. Откроется чёрное окно со списком операций — введите нужную (например `to-jpg`) и нажмите Enter. Готовый файл появится рядом с исходным.

Консольный вариант: `dropwheel-cli.exe convert "C:\Мои фото\тест 1.heic" to-jpg`, список операций — `dropwheel-cli.exe list`.

## Конфиденциальность

- **100% офлайн.** Вся конвертация — на вашем компьютере. Файлы никуда не загружаются: отправлять их просто некуда.
- **Никакой телеметрии, аналитики, учётных записей и рекламы.**
- **Единственное, что программа делает в сети, — проверка обновлений:** раз в сутки (и по кнопке «Проверить обновления») она читает маленький файл `version.json` из [релизов](https://github.com/Luchano55/dropwheel/releases/tag/dev-build) этого репозитория. Ни файлы, ни личные данные не отправляются; обновление ставится, только когда вы нажмёте «Обновить», и проверяется по SHA-256. Отключить совсем: `"checkForUpdates": false` в `%AppData%\DropWheel\settings.json`.
- Настройки и журналы лежат у вас: `%AppData%\DropWheel`. В журнале есть пути к файлам и тексты ошибок — гляньте его, прежде чем прикладывать к сообщению об ошибке.

## Частые вопросы

<details>
<summary><b>Это правда бесплатно?</b></summary>

Да. Открытый код под лицензией MIT: без рекламы, пробного периода, «про-версии» и ограничений.
</details>

<details>
<summary><b>Программа может испортить или удалить исходный файл?</b></summary>

Нет. Результат сначала пишется во временный файл и только потом переименовывается — если конвертация сорвалась, недоделанного файла не останется. Занятое имя → `photo (1).jpg`, `photo (2).jpg`…
</details>

<details>
<summary><b>Колесо не появляется по Пробелу.</b></summary>

- Проверьте, что DropWheel запущен (значок-кольцо в трее).
- Жмите <kbd>Пробел</kbd> <i>во время</i> перетаскивания, не отпуская кнопку мыши.
- Windows не даёт обычным программам работать с окнами, запущенными от администратора, — из таких окон колесо не сработает.
- Файлы, которые тащат из браузера, часто ещё не лежат на диске — сначала сохраните их.
</details>

<details>
<summary><b>Пробел мешает. Можно другую клавишу?</b></summary>

Да. Закройте DropWheel, откройте `%AppData%\DropWheel\settings.json` и поставьте в `"hotkey"` значение `"Backquote"` (клавиша <kbd>Ё</kbd> / <kbd>`</kbd>), `"CapsLock"` или `"F1"`…`"F12"`, затем запустите программу снова. Окно настроек — в планах.
</details>

<details>
<summary><b>Запускается ли вместе с Windows?</b></summary>

Пока нет — автозапуск появится вместе с окном настроек. А сейчас: <kbd>Win</kbd>+<kbd>R</kbd> → `shell:startup` → положите туда ярлык `DropWheel.exe`.
</details>

<details>
<summary><b>Как обновиться и какая у меня сборка?</b></summary>

Раз в сутки программа сама проверяет, нет ли новой сборки, и предлагает «Обновить до сборки N» в меню значка. Правый клик по значку → «Проверить обновления» — проверить прямо сейчас (заодно покажет номер вашей сборки). Можно и вручную: скачать полный архив из <a href="https://github.com/Luchano55/dropwheel/releases/tag/dev-build">Releases</a> и распаковать поверх старой папки.
</details>

<details>
<summary><b>Почему архив такой большой?</b></summary>

В нём ffmpeg, ImageMagick, qpdf и poppler — чтобы всё работало офлайн сразу после распаковки, без докачки и настройки. Основной вес — это они.
</details>

<details>
<summary><b>Что-то сломалось. Как сообщить?</b></summary>

Правый клик по значку → «Открыть журнал», возьмите самый свежий файл `.log` и приложите к <a href="https://github.com/Luchano55/dropwheel/issues/new/choose">сообщению об ошибке</a> вместе с версией Windows и номером сборки DropWheel.
</details>

## Для разработки

- .NET 8 SDK; для интеграционных тестов — `ffmpeg` и ImageMagick в PATH (или переменные `DROPWHEEL_FFMPEG` / `DROPWHEEL_MAGICK`); для PDF — `qpdf` и `pdftoppm` (poppler-utils; `DROPWHEEL_QPDF` / `DROPWHEEL_PDFTOPPM`).
- `dotnet test` — все тесты; без утилит интеграционные тесты пропускаются.
- Сборка для Windows делается автоматически (GitHub Actions, `.github/workflows/build.yml`): тесты на Linux и Windows, затем архив с `tools/` выкладывается в релиз `dev-build`. Утилиты скачивает `build/fetch-tools.ps1`.
- Документы: `docs/spec.md` (ТЗ), `docs/decisions.md`, `docs/questions.md`, `CLAUDE.md`.

```bash
git clone https://github.com/Luchano55/dropwheel.git
cd dropwheel
dotnet build
dotnet test
```

Новая операция — одна строка в каталоге [`OperationCatalog.cs`](src/DropWheel.Core/Conversions/OperationCatalog.cs): id, подпись, тип входа, движок, шаблон аргументов, расширение результата. Сообщения об ошибках и pull request'ы — приветствуются.

## Лицензии сторонних программ

Архив сборки содержит:
- **ffmpeg** — GPL-сборка [BtbN/FFmpeg-Builds](https://github.com/BtbN/FFmpeg-Builds) (лицензия GPL v3, исходный код — там же и на [ffmpeg.org](https://ffmpeg.org)); текст лицензии — `tools/ffmpeg/LICENSE.txt`.
- **ImageMagick** — portable-сборка с [imagemagick.org](https://imagemagick.org) (лицензия ImageMagick, Apache-2.0-совместимая).
- **qpdf** — официальная сборка [qpdf/qpdf](https://github.com/qpdf/qpdf) (лицензия Apache-2.0).
- **poppler** (`pdftoppm`) — сборка [oschwartz10612/poppler-windows](https://github.com/oschwartz10612/poppler-windows) (лицензия GPL-2.0 или новее, исходный код — на [poppler.freedesktop.org](https://poppler.freedesktop.org)).

DropWheel запускает их как отдельные программы и не изменяет.

Программа написана на [.NET 8](https://dotnet.microsoft.com) и WPF; уведомления — [Microsoft.Toolkit.Uwp.Notifications](https://github.com/CommunityToolkit/WindowsCommunityToolkit) (MIT). Надписи на картинках — шрифтом [Inter](https://rsms.me/inter/) (SIL OFL 1.1).
